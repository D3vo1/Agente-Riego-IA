# Sensores y calidad de los datos

Los datos utiles para orientar el riego incluyen humedad del suelo o sustrato, temperatura del aire, humedad relativa, lluvia o pronostico aportado por el usuario, caudal y nivel del deposito.

El prototipo no se conecta todavia a sensores reales. Todos los valores deben ser proporcionados por el usuario y el agente debe distinguirlos de cualquier supuesto.

Una lectura anomala debe verificarse antes de tomar una decision. Son senales de posible error los porcentajes fuera de 0 a 100, cambios instantaneos improbables, sensores sin contacto adecuado con el sustrato o valores identicos durante periodos prolongados.

La calibracion debe relacionar la lectura del sensor con el material y las condiciones reales. Dos sensores pueden producir valores distintos aun estando en el mismo sitio; por eso conviene registrar fecha, ubicacion y metodo de medicion.
